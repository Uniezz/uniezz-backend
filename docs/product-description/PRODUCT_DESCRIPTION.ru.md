# Uniezz — Описание продукта

## Обзор

**Uniezz** — веб-приложение для студентов университетов Люблина. Платформа объединяет студентов пяти вузов города в одном пространстве: общение, обмен знаниями, полезная информация о жизни в Люблине и поиск новых знакомств.

### Целевые университеты

- **UMCS** — Университет Марии Склодовской-Кюри
- **KUL** — Католический университет Люблина
- **Politechnika Lubelska** — Люблинская политехника
- **Uniwersytet Przyrodniczy** — Университет естественных наук
- **WSEI** — Высшая школа экономики и инноваций

## Основные модули

### 1. Авторизация

Вход через учётные записи университетских сервисов (предположительно **Moodle** и аналогичные системы каждого вуза). Это гарантирует, что доступ к платформе имеют только действующие студенты.

- Единый вход (SSO) через интеграцию с вузовскими системами
- Привязка профиля к конкретному университету, факультету и курсу
- Верификация статуса студента

### 2. Профиль и связи

- Личный профиль: фото, имя, университет, факультет, курс, интересы
- Список связей (друзья, однокурсники, знакомые)
- Настройки приватности
- Возможность находить студентов своего и других вузов Люблина

### 3. Лента постов (объявления)

Социальная лента для студенческого сообщества:

- **Объявления** — продажа/покупка, поиск соседа по комнате, услуги
- **Мероприятия** — вечеринки, встречи, конференции, спортивные события
- **Вопросы** — помощь по учёбе, бытовые вопросы, советы новичкам
- **Комментарии** — обсуждение под каждым постом
- Фильтрация по университету, категории и дате

### 4. Чат (мессенджер)

Встроенный мессенджер для личного и группового общения:

- Личные сообщения между пользователями
- Групповые чаты (по предмету, факультету, общежитию и т.д.)
- Уведомления о новых сообщениях
- Отправка текста и медиафайлов (с модерацией)

### 5. Учёба и помощь студентам

Раздел для академической поддержки:

- **Экзамены прошлых лет** — архив заданий, билетов, тестов
- **Оценки и отзывы** — рейтинги и комментарии о преподавателях и предметах
- **Описание предметов** — программа, сложность, рекомендации по подготовке
- Поиск и фильтрация по вузу, факультету, семестру и предмету
- Возможность оставлять комментарии и дополнять материалы

### 6. Справочник студента (базовая информация)

Практический гид по жизни в Люблине для студентов:

- **Покупки** — где дешевле закупаться, сравнение магазинов (Biedronka, Lidl, Carrefour и др.)
- **Места для досуга** — кафе, бары, парки, культурные места
- **Общежития** — описание, стоимость проживания, условия, отзывы студентов
- **Магазины рядом** — что где купить (продукты, канцтовары, техника, одежда)
- Карта с отмеченными точками интереса

### 7. Знакомства (Tinder-like)

Модуль для поиска друзей, общения и отношений:

- Карточки пользователей с фото, интересами и университетом
- Свайп-механика: лайк / пропуск
- Матч при взаимном интересе — открывается чат
- Фильтры: университет, курс, цели (друзья / отношения / общение)
- Строгая модерация профилей и фотографий

## Мультиязычность

Приложение поддерживает четыре языка:

| Язык | Код |
|------|-----|
| Польский | `pl` |
| Украинский | `uk` |
| Русский | `ru` |
| Английский | `en` |

- Переключение языка в настройках профиля
- Локализация всего интерфейса
- Пользовательский контент отображается на языке автора; интерфейс — на выбранном языке

## Модерация и безопасность

Строгая модерация контента — ключевой принцип платформы:

- **Тексты** — автоматическая и ручная проверка на оскорбления, расизм, дискриминацию, травлю и негатив
- **Медиа** — проверка загружаемых фото и видео
- **Жалобы** — пользователи могут сообщать о нарушениях
- **Санкции** — предупреждения, временная блокировка, перманентный бан
- **Модераторы** — команда из представителей каждого вуза

## Ценность для студентов

| Проблема | Решение в Uniezz |
|----------|------------------|
| Разрозненные чаты и группы в соцсетях | Единая платформа для всех вузов Люблина |
| Сложно найти материалы к экзаменам | Архив экзаменов и отзывы о предметах |
| Новичок не знает, где жить и что покупать | Справочник с актуальной информацией |
| Сложно познакомиться вне своего вуза | Модуль знакомств между студентами города |
| Токсичный контент в открытых группах | Строгая модерация и верификация студентов |

## Технический стек (планируемый)

- **Frontend:** React + TypeScript + Vite + TanStack Router (веб); Expo / React Native (мобильный)
- **Backend:** Go — собственный API. Без Supabase и других BaaS; веб и мобильный клиент обращаются только к этому API
- **Авторизация:** USOS (OAuth 1.0a), Microsoft Entra ID (OIDC), email OTP как запасной вариант — см. `docs/auth/`
- **Медиа:** AWS S3 — фото, вложения в чате, файлы экзаменов и прочие загрузки пользователей
