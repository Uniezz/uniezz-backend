# Uniezz — Опис продукту

## Огляд

**Uniezz** — веб-додаток для студентів університетів Любліна. Платформа об'єднує студентів п'яти вузів міста в одному просторі: спілкування, обмін знаннями, корисна інформація про життя в Любліні та пошук нових знайомств.

### Цільові університети

- **UMCS** — Університет Марії Склодовської-Кюрі
- **KUL** — Католицький університет Любліна
- **Politechnika Lubelska** — Люблінська політехніка
- **Uniwersytet Przyrodniczy** — Університет природничих наук
- **WSEI** — Вища школа економіки та інновацій

## Основні модулі

### 1. Авторизація

Вхід через облікові записи університетських сервісів (ймовірно **Moodle** та аналогічні системи кожного вузу). Це гарантує, що доступ до платформи мають лише діючі студенти.

- Єдиний вхід (SSO) через інтеграцію з вузівськими системами
- Прив'язка профілю до конкретного університету, факультету та курсу
- Верифікація статусу студента

### 2. Профіль і зв'язки

- Особистий профіль: фото, ім'я, університет, факультет, курс, інтереси
- Список зв'язків (друзі, однокурсники, знайомі)
- Налаштування приватності
- Можливість знаходити студентів свого та інших вузів Любліна

### 3. Стрічка постів (оголошення)

Соціальна стрічка для студентської спільноти:

- **Оголошення** — продаж/купівля, пошук сусіда по кімнаті, послуги
- **Заходи** — вечірки, зустрічі, конференції, спортивні події
- **Питання** — допомога з навчанням, побутові питання, поради новачкам
- **Коментарі** — обговорення під кожним постом
- Фільтрація за університетом, категорією та датою

### 4. Чат (месенджер)

Вбудований месенджер для особистого та групового спілкування:

- Особисті повідомлення між користувачами
- Групові чати (за предметом, факультетом, гуртожитком тощо)
- Сповіщення про нові повідомлення
- Надсилання тексту та медіафайлів (з модерацією)

### 5. Навчання та допомога студентам

Розділ для академічної підтримки:

- **Іспити минулих років** — архів завдань, білетів, тестів
- **Оцінки та відгуки** — рейтинги та коментарі про викладачів і предмети
- **Опис предметів** — програма, складність, рекомендації щодо підготовки
- Пошук і фільтрація за вузом, факультетом, семестром і предметом
- Можливість залишати коментарі та доповнювати матеріали

### 6. Довідник студента (базова інформація)

Практичний гід по життю в Любліні для студентів:

- **Покупки** — де дешевше закуповуватися, порівняння магазинів (Biedronka, Lidl, Carrefour тощо)
- **Місця для дозвілля** — кав'ярні, бари, парки, культурні місця
- **Гуртожитки** — опис, вартість проживання, умови, відгуки студентів
- **Магазини поруч** — що де купити (продукти, канцтовари, техніка, одяг)
- Карта з позначеними точками інтересу

### 7. Знайомства (Tinder-like)

Модуль для пошуку друзів, спілкування та стосунків:

- Картки користувачів із фото, інтересами та університетом
- Свайп-механіка: лайк / пропуск
- Матч при взаємному інтересі — відкривається чат
- Фільтри: університет, курс, цілі (друзі / стосунки / спілкування)
- Сувора модерація профілів і фотографій

## Модерація та безпека

Сувора модерація контенту — ключовий принцип платформи:

- **Тексти** — автоматична та ручна перевірка на образи, расизм, дискримінацію, булінг і негатив
- **Медіа** — перевірка завантажених фото та відео
- **Скарги** — користувачі можуть повідомляти про порушення
- **Санкції** — попередження, тимчасове блокування, постійний бан
- **Модератори** — команда з представників кожного вузу

## Цінність для студентів

| Проблема | Рішення в Uniezz |
|----------|------------------|
| Розрізнені чати та групи в соцмережах | Єдина платформа для всіх вузів Любліна |
| Важко знайти матеріали до іспитів | Архів іспитів і відгуки про предмети |
| Новачок не знає, де жити і що купувати | Довідник з актуальною інформацією |
| Важко познайомитися поза своїм вузом | Модуль знайомств між студентами міста |
| Токсичний контент у відкритих групах | Сувора модерація та верифікація студентів |

## Технічний стек (плановий)

- **Frontend:** React + TypeScript + Vite + TanStack Router (веб); Expo / React Native (мобільний)
- **Backend:** Go — власне API. Без Supabase та інших BaaS; веб і мобільний клієнт звертаються лише до цього API
- **Авторизація:** USOS (OAuth 1.0a), Microsoft Entra ID (OIDC), email OTP як запасний варіант — див. `docs/auth/`
- **Медіа:** AWS S3 — фото, вкладення в чаті, файли іспитів та інші завантаження користувачів
