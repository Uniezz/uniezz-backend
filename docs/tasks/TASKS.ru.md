# Uniezz — Задачи бэкенда

Go API. Без Supabase. Файлы в AWS S3. Веб и телефон только к этому API.

Оценки: **0.5d или 1d**. Спринт = две недели, около 10d.

---

## Спринт 1 — Студент может войти

**Цель:** Студент UMCS и студент одного вуза Entra могут войти. Есть health check и база.

**Не в этом спринте:** лента, чат, Meet, гид, вход модератора.

| ID | Задача | d | Зависит | Готово, когда |
|----|--------|---|---------|---------------|
| BE-1.1 | Запустить Go API | 1 | — | `/health` работает. Старый Express убран. |
| BE-1.2 | Выбрать базу и миграции | 1 | BE-1.1 | Можно создать и запустить одну миграцию. Выбор записан. |
| BE-1.3 | Таблицы user, session, код с почты | 1 | BE-1.2 | Таблицы есть. Приложение стартует. |
| BE-1.4 | Cookie сессии, «кто я», выход | 1 | BE-1.3 | Cookie HttpOnly. `/auth/me` и `/auth/logout` работают. |
| BE-1.5 | Как телефон держит логин | 0.5 | BE-1.4 | Есть cookie или token. API это умеет. |
| BE-1.6 | Старт входа и возврат из вуза | 1 | BE-1.4 | Есть `/auth/start` и `/auth/callback` для usos, entra, otp. |
| BE-1.7 | Зарегистрировать USOS и спрятать ключи | 1 | BE-1.6 | Ключи в секретах, не в git. |
| BE-1.8 | Закончить вход через USOS | 1 | BE-1.7 | Студент UMCS возвращается с именем и почтой. PESEL не сохраняется. |
| BE-1.9 | Entra и только наши вузы | 1 | BE-1.6 | Чужой tenant отклонён. |
| BE-1.10 | Блокировать сотрудников Entra | 1 | BE-1.9 | Сотрудник не получает студенческую сессию. |
| BE-1.11 | Отправить код на почту | 1 | BE-1.6 | Только университетская почта. Код в хеше. |
| BE-1.12 | Проверить код и лимиты | 0.5 | BE-1.11 | 3 кода на почту / час, 10 на IP, 5 попыток, потом код сгорает. |
| BE-1.13 | Один профиль и бейдж доверия | 0.5 | BE-1.8, BE-1.10, BE-1.12 | `/auth/me` показывает verified, directory или domain. |

**Итого: 11.5d** (если нет живого Entra-студента — доказать один tenant в спринте 2.)
